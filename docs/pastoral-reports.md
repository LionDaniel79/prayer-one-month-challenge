# 목양지 — 월별 제출

관리자 → 목양지 관리에서 올해·내년의 1~12월을 선택하고 저장합니다. 주별 설정이나 별도 시작일·마감일은 없습니다. 서울 시간 기준 해당 달 안에서만 제출할 수 있습니다. 과거·미래 월은 !를 표시하지 않습니다. 해당 샘에 사진/파일/직접 입력 중 하나의 완료된 목양지가 1건 이상 있으면 이번 달 !가 사라집니다. 같은 달 추가 제출도 가능합니다.

마을장은 관리자 → 사용자 관리 → 샘 리더 관리의 마을장 등록에서 `1마을장`과 성도 명단의 이름으로 등록합니다. 별도의 목양지 권한 관리는 없습니다. 샘 리더는 기존 등록 명단, 마을장은 신규 마을장 등록과 동일 마을 성도 명단을 대조합니다. 동명이인/소속 불일치/비활성은 자동으로 권한을 부여하지 않습니다. A/B 이름 구분자를 유지합니다. 마을장은 해당 마을 샘에 제출할 수 있고 다른 사람의 본문을 볼 수는 없습니다. 관리자만 전체 본문을 조회합니다.

작성일은 오늘 날짜로 자동 입력되며 수정할 수 있습니다. 공동체 칸은 없으며 제출자는 현재 로그인한 사용자로 서버에서 기록합니다. 본문은 일부 또는 전부 비워 제출할 수 있습니다. ‘이번 기간 샘모임 없음’을 선택한 경우에만 이유 입력이 필수입니다. 사진/파일은 각 6MiB, 최대 2개입니다. 관리자는 사진 미리보기/원본 다운로드, 직접 입력 화면/TXT 다운로드를 사용할 수 있습니다. 첨부 업로드 실패는 완료로 집계되지 않습니다. 같은 전송의 재시도는 중복 제출하지 않습니다.

DB 적용: `drizzle/20260930000000_pastoral_reports.sql`은 처음 배포하는 추가형 migration입니다. 운영 자료·암호화 키는 변경하지 않습니다. village_leaders와 pastoral 테이블 4개는 RLS와 공개 역할 권한 회수로 서버 전용입니다. 원본 사진의 개인정보는 소스/테스트에 포함하지 않습니다. 실제 운영 데이터로 테스트하지 않습니다.

최종 제출은 수정/삭제 대신 같은 달 추가 제출로 정정합니다. 미완성 초안은 최대 3개/24시간이며 다음 작성 시작 시 만료 정리합니다. 첨부는 DB 공간을 사용하며 바이러스 검사는 아닙니다.
