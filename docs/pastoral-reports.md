# 목양지 — 월별 제출과 정정

## 메뉴와 대상
회원 화면에서는 커뮤니티 아래 **목양지** 탭을 사용합니다. 관리자·샘 리더·마을장에게 표시되며 일반 회원에게는 표시되지 않습니다. API도 동일하게 권한을 검사합니다.

마을장 등록은 **관리자 → 사용자 관리 → 샘 리더 관리 → 마을장 등록**입니다. `1마을장`과 성도 명단의 이름을 입력합니다. 활성 성도 명단 전체에서 이름이 한 명이면 자동 연결하고, 동명이인이면 관리자가 정확한 성도를 선택해 고유 ID로 연결합니다. 마을장은 실제 소속 마을·샘과 담당 마을이 달라도 지정할 수 있으며, 담당 마을의 샘에만 목양지 제출 권한이 적용됩니다. 선택하지 않은 동명이인에게는 권한이 부여되지 않습니다. 샘 리더는 기존 명단을 사용합니다. 마을장은 해당 마을 샘에 제출할 수 있지만 다른 사람의 본문을 볼 수 없습니다.

## 월별 제출
관리자 → 목양지 관리에서 올해·내년의 1~12월을 선택하고 저장합니다. 주별 설정이나 별도 시작일·마감일은 없습니다. 서울 시간 기준 해당 달 안에서 새로 제출할 수 있습니다. 과거·미래 월은 !를 표시하지 않습니다. 해당 샘에 사진/파일/직접 입력 중 하나의 완료된 목양지가 한 건 이상 있으면 이번 달 !가 사라집니다. 같은 달 추가 제출도 가능합니다.

작성일은 오늘 날짜로 자동 입력되며 수정할 수 있습니다. 공동체 칸은 없고 제출자는 로그인한 사용자로 서버에서 기록합니다. 본문은 일부 또는 전부 비워 제출할 수 있습니다. ‘이번 기간 샘모임 없음’을 선택한 경우에만 이유를 작성합니다. 양식은 샘모임, 나눔/기도제목, 샘소식, 샘리더 기도제목, 기타 순서입니다. 상담/심방 요청 항목은 제거했습니다.

## 수정·삭제
‘내가 제출한 목양지’에서 제출본을 열면 **목양지 수정 / 목양지 삭제** 버튼이 보입니다. 관리자는 관리자 → 목양지 관리의 제출본 상세에서 본인과 다른 작성자의 완료본을 수정·삭제할 수 있습니다. 일반 화면에서는 관리자도 다른 작성자의 수정·삭제 버튼이 보이지 않습니다.

수정은 작성일, 입력 내용, 제출 방식, 첨부의 유지/삭제/추가/교체를 지원합니다. 기존 제출 월·샘·원래 작성자·제출 완료일시는 바뀌지 않습니다. 해당 달이 지났거나 월별 요청이 해제되어도 기존 제출본을 정정할 수 있습니다. 새 제출의 월 제한과는 별개입니다.

첨부는 남겨 둔 파일과 새 파일을 합해 최대 2개, 각각 6MiB입니다. 사진/파일은 최소 1개가 필요하며, 파일 없이 바꾸려면 ‘직접 입력’을 선택합니다. 교체 전송이 실패하거나 수정을 취소하면 기존 자료는 유지됩니다. 최종 저장 성공 시에만 새 내용과 첨부를 함께 반영합니다. 같은 저장을 재시도해도 중복 적용하지 않고, 다른 사람이 먼저 수정한 버전에는 덮어쓰지 않습니다.

삭제 시 확인창이 표시됩니다. 삭제하면 첨부와 수정 초안도 정리되며 되돌릴 수 없습니다. 이번 달의 마지막 제출본을 삭제하면 해당 샘 리더의 !가 다시 나타납니다. 미완성 초안 취소는 별도 처리하므로 완료본을 지우지 않습니다.

## 관리자 보기와 파일
월 아래 제출 대상 명단은 기본 접힘 상태이며 제목을 눌러 펼치고 접습니다. 관리자 상세와 목록에서는 제출일시·제출방법을 표시하지 않습니다. 작성일, 샘, 샘리더, 원래 제출자는 확인할 수 있습니다. 사진 미리보기/원본 다운로드와 직접 입력 내용/TXT 다운로드를 지원합니다. TXT에는 기타가 포함되며 제거한 상담/심방 항목은 나오지 않습니다. 예전 상담/심방 JSON은 마이그레이션이나 양식 정정으로 임의 삭제하지 않습니다.

## Google Calendar 위치
별도 ‘설정’ 메뉴와 새 공지 Push 카드는 제거했습니다. **관리자 → 심방 신청 관리의 가장 아래**에서 Google Calendar를 관리합니다. 이전 설정 주소는 새 위치로 이동합니다. OAuth callback 경로와 기존 토큰·암호화 키는 그대로입니다. Production 서버 환경변수가 미설정인 경우에는 패널을 옮겨도 연결되지 않으므로 기존 값을 Vercel Production에 적용해야 합니다.

주소를 56love로 전환하는 일은 [도메인 전환 안내](56love-domain-transition.md)를 따릅니다. 실제 도메인 연결 전에는 기존 정식 주소를 사용합니다.

## DB·운영
최초 기능은 `drizzle/20260930000000_pastoral_reports.sql`, 수정 기능은 `drizzle/20260930073000_pastoral_report_revisions.sql`입니다. 기존 보고서에 버전/수정자 정보와 비공개 수정 초안 테이블 두 개를 추가합니다. 이미 적용한 DB에는 중복 실행하지 않습니다. 모든 신규 테이블은 RLS와 공개 역할 권한 회수로 서버 전용입니다.

미완성 새 제출/수정 초안은 각각 최대 3개이며 24시간 후 다음 초안 생성 때 정리됩니다. 첨부는 DB 공간을 사용하며 백신 검사는 제공하지 않습니다. 실제 성도 자료나 비밀값을 테스트/로그/공개 저장소에 넣지 않습니다.
