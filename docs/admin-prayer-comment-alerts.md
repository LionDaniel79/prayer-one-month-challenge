# 관리자 기도요청 댓글 알림

관리자 대시보드의 ‘미처리 기도요청’ 오른쪽 ‘댓글 알림’은 확인하지 않은 신청자 댓글 수를 표시한다. 여러 댓글이 달리면 각각 계산하며, 관리자 댓글과 이미 확인한 댓글은 제외한다. 기도요청의 접수·기도중·완료 상태와 관계없이 새 댓글을 알려준다.

알림을 누르면 ‘댓글 미확인’으로 필터한 기도요청 관리가 열린다. 요청을 선택한 뒤 댓글이 실제 화면에 표시되면 읽음 처리한다. 읽음 기록은 관리자들이 함께 사용하며 신청자에게 표시되는 관리자 댓글 느낌표와는 별개다. 대시보드는 열린 상태에서 15초마다, 화면 복귀 시에도 갱신한다.

`drizzle/20261022215952_prayer_admin_comment_reads.sql`을 배포 전에 적용한다. 기존 테이블의 RLS와 접근 권한은 바꾸지 않는다. 기존 댓글은 관리자 확인 기록이 없으므로 처음에는 미확인으로 표시하며, 댓글 수정만으로 새 알림을 만들지는 않는다. 요청별 순번과 행 잠금을 사용해 화면 조회 후 도착한 댓글이 이전 읽음 처리에 포함되지 않도록 한다.
