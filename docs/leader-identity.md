# 샘리더·마을장 동명이인 처리

사용자 관리 → 샘 리더 관리에서 기존처럼 소속과 이름을 입력합니다. 활성 성도 명단의 원래 이름 또는 로그인 이름에 한 명만 해당하면 별도 선택 없이 자동 연결됩니다. 동명이인이 여러 명이면 이름·마을·샘·전화번호 뒤 네 자리를 확인해 한 사람을 선택한 뒤 저장합니다. 다른 소속의 후보는 표시하되 지정할 수 없습니다. 전화번호를 읽을 수 없을 때는 임의 숫자 대신 확인 불가를 표시합니다.

기존 명단은 전역 이름 후보가 한 명이고 소속도 맞을 때만 자동 이관합니다. 이름이 같은 후보가 다른 마을에 있어도 확인 필요로 남깁니다. 관리자는 접힌 등록 명단을 펼쳐 ‘동명이인 확인 필요’ 항목의 수정 버튼에서 선택할 수 있습니다. 연결되지 않은 성도에게는 리더 권한을 주지 않습니다. 새로운 전용 권한 관리 메뉴는 만들지 않았습니다.

연결 후에는 이름 대신 성도 명단 ID로 권한을 확인합니다. 이름 변경이나 동명이인 추가는 기존 연결을 바꾸지 않습니다. 아직 로그인하지 않은 성도도 지정할 수 있고 첫 로그인 때 동일한 ID로 연결됩니다. 비활성·소속 변경 시 권한을 차단하고, 성도 삭제로 ID가 사라져도 다른 동명이인에게 자동 이전하지 않습니다. 이 경우 정확한 새 성도를 확인해 다시 지정합니다. 같은 리더 이름의 엑셀 재가져오기는 기존 연결을 보존합니다. 새 이름이 모호하면 등록 정보만 가져오고 확인 필요로 남깁니다.

마이그레이션은 `drizzle/20260930090000_leader_roster_identity.sql`입니다. 기존 성도, 목양지, 첨부파일, Google 연결 및 비밀값을 변경하지 않습니다. 운영 동명이인의 실명·전화번호는 공개 저장소의 문서나 테스트에 기록하지 않습니다.
