# 샘리더·마을장 동명이인 처리

사용자 관리 → 샘 리더 관리에서 기존처럼 소속과 이름을 입력합니다. 활성 성도 명단의 원래 이름 또는 로그인 이름에 한 명만 해당하면 별도 선택 없이 자동 연결됩니다. 동명이인이 여러 명이면 이름·마을·샘·전화번호 뒤 네 자리를 확인해 한 사람을 선택한 뒤 저장합니다. 마을장은 실제 소속 마을·샘과 담당 마을이 달라도 지정할 수 있습니다. 후보의 마을·샘은 본인의 소속 정보이며, 목양지 권한은 등록한 담당 마을에만 적용됩니다. 샘리더는 기존처럼 해당 샘 소속만 지정할 수 있습니다. 전화번호를 읽을 수 없을 때는 임의 숫자 대신 확인 불가를 표시합니다.

최초 이관은 전역 이름 후보가 한 명이고 소속도 맞는 등록만 처리했습니다. 이후 마을장 등록·재대조는 실제 소속 마을과 무관하게 유일한 이름을 자동 연결하며, 동명이인은 관리자가 선택해야 합니다. 샘리더의 소속 샘 확인은 유지됩니다. 이름이 같은 후보가 다른 마을에 있어도 확인 필요로 남깁니다. 관리자는 접힌 등록 명단을 펼쳐 ‘동명이인 확인 필요’ 항목의 수정 버튼에서 선택할 수 있습니다. 연결되지 않은 성도에게는 리더 권한을 주지 않습니다. 새로운 전용 권한 관리 메뉴는 만들지 않았습니다.

연결 후에는 이름 대신 성도 명단 ID로 권한을 확인합니다. 이름 변경이나 동명이인 추가는 기존 연결을 바꾸지 않습니다. 아직 로그인하지 않은 성도도 지정할 수 있고 첫 로그인 때 동일한 ID로 연결됩니다. 성도나 역할이 비활성이면 권한을 차단합니다. 샘리더는 소속 샘을 벗어나면 권한을 차단하지만, 마을장은 본인의 소속 마을·샘이 바뀌어도 담당 마을 권한을 유지합니다. 성도 삭제로 ID가 사라져도 다른 동명이인에게 자동 이전하지 않습니다. 이 경우 정확한 새 성도를 확인해 다시 지정합니다. 같은 리더 이름의 엑셀 재가져오기는 기존 연결을 보존합니다. 새 이름이 모호하면 등록 정보만 가져오고 확인 필요로 남깁니다.

마이그레이션은 `drizzle/20260930090000_leader_roster_identity.sql`입니다. 기존 성도, 목양지, 첨부파일, Google 연결 및 비밀값을 변경하지 않습니다. 운영 동명이인의 실명·전화번호는 공개 저장소의 문서나 테스트에 기록하지 않습니다.
