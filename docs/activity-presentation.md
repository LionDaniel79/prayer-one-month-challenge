# 운동 이름과 설명 설정

관리자 → 기도운동 관리(이름 변경 후에는 해당 이름 + 관리) → 화면 아래 **운동 이름·설명 및 탭 설정**에서 수정합니다.

- **운동 이름**: 최대 40자. 사용자·관리자 메뉴, 운동 화면 제목과 관리자 요약에 반영됩니다.
- **운동 설명**: 최대 2,000자. 줄바꿈을 유지해 사용자 운동 화면에 표시합니다. 비워 두면 설명을 숨깁니다.
- **운동 탭 활성화**: 기존과 동일하게 모든 사용자에게 탭을 표시하거나 숨깁니다.
- 저장 후 열려 있는 사용자 화면은 30초 이내 또는 화면으로 돌아올 때 새 설정을 확인합니다.
- **도전 설정**의 도전 제목은 기간별 제목입니다. 운동 이름과 별도로 수정할 수 있습니다.
- 시작일·종료일을 직접 지정할 수 있습니다. 시작일 변경 시 한 달 기준 종료일을 제안하므로, 다른 기간을 원하면 종료일을 다시 지정합니다.
- 참여 체크 규칙은 월~토요일, 서울 기준 오늘·어제입니다. 일요일과 과거 날짜의 체크 규칙을 바꾸는 기능은 포함하지 않습니다.
- 이름·설명 수정은 기존 도전 기간, 참여 체크 및 통계를 변경하지 않습니다. 서로 다른 운동의 기록을 자동 분리하거나 초기화하지 않습니다.

## 기존 설치 업데이트

앱 배포 전에 `drizzle/20261015130000_activity_presentation.sql`을 기존 설치 DB에 한 번 적용합니다. 기존 `prayer_app.prayer_menu_settings` 테이블에 기본 이름과 빈 설명 열을 추가하는 변경이며, 현재 활성화 여부와 기록은 보존됩니다. 기존 RLS와 권한도 유지합니다.

새로 설치할 때는 기존과 같이 `drizzle/*.sql`을 파일명 순서대로 적용합니다.

관리자 API만 수정 권한을 가지며 일반 사용자는 로그인 후 이름·설명을 조회할 수 있습니다. 이전 클라이언트의 활성화 여부만 저장하는 요청은 이름·설명을 덮어쓰지 않습니다.
