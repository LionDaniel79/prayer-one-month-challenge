# 목양지 관리 개선 / 56love 전환 준비

## 사용자 요구와 범위
기존 Production 8354077을 기준으로 목양지 메뉴명, 마을장 표시, 소유자/관리자 수정·삭제, 선택 입력 양식, 관리자 접기, 캘린더 위치를 개선한다. 사용자에게 중간 확인을 요구하지 않는 진행 지시에 따라 아래 안전한 기본값으로 작업한다.

## 결정
- 회원 메뉴 이름은 `목양지`. 기존 `/pastoral-reports` URL/API를 유지한다.
- 마을장 매칭은 등록 마을+원래 이름 또는 로그인용 이름. 같은 마을 후보가 2명 이상이면 권한을 주지 않는다. 다른 마을의 동명이인도 권한을 받지 않는다.
- 소유자는 본인 제출본만, 관리자는 관리자 화면에서 전체 완료본을 수정/삭제한다. 작성 월이 지나거나 월 요청이 해제되어도 기존 제출본 정정 가능. 새로운 제출만 기존 월별 규칙을 따른다.
- 수정은 작성일/제출 방식/직접 입력/첨부 추가·제거·교체. 원래 작성자, 제출 월, 샘, 완료일시는 유지. 수정 이력 정보(version/updated_at/updated_by)는 서버 저장만 한다.
- 512KiB 분할 전송, 파일당 6MiB 최대2개. 별도 수정 초안과 조각 테이블에서 검증 후 단일 트랜잭션으로 교체. optimistic version과 idempotency key로 덮어쓰기 및 재시도 중복을 막는다.
- 삭제는 명시적인 완료본 전용 endpoint와 확인창. 기존 초안 취소 API는 완료본 삭제에 사용하지 않는다. 삭제 후 남은 완료본이 없으면 당월 `!` 복구.
- 상담/심방 요청을 새 양식·상세·TXT에서 제거. 예전 JSON의 해당 값은 마이그레이션/정정으로 소실시키지 않는다. 기타 텍스트(5000자)를 샘리더 기도제목 뒤 추가. 모두 선택, 모임없음 사유는 기존 필수 유지.
- 관리자 상세/목록에 제출일시·제출방법 미표시. 월별 대상 명단은 기본 접힘 details/summary로 표시.
- 관리자 설정 메뉴 제거. 기존 settings URL은 visits#google-calendar로 redirect. 캘린더 UI를 심방신청 관리 마지막에 이동. OAuth callback endpoint 및 암호화 키/DB 연결은 유지하고 연결 완료 이동 위치만 변경. Push 설정 카드는 화면에서 제거하며 기존 공지 읽음은 유지.
- 주소는 코드 문자열 전체 치환으로 바꾸지 않는다. npm package/DB/repository 식별자는 URL과 무관하므로 유지, 상대경로 URL 유지. 실제 Vercel 도메인은 권한/사용가능 여부 확인 전 기존 주소 유지. 저장소·DB 식별자와 과거 이력은 유지한다.

## 안전성과 완료 기준
기존 운영 자료/토큰/비밀값을 읽어 출력하거나 초기화하지 않는다. 가상 계정+일회용 DB로 정책/권한/경합/파일/모바일 검증. RED→GREEN 후 전체 CI, 추가형 DB 적용, Production deploy metadata+공개 접속 확인. 권한 실패로 처리할 수 없는 도메인 연결은 성공으로 보고하지 않는다.
