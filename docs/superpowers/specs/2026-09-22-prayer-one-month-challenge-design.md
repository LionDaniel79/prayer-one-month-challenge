# 기도운동 1달 도전 — 설계 문서

작성일: 2026-09-22

## 1. 목표

약 200명의 성도가 휴대폰으로 접속해 한 달 동안 월~토 기도 완료 여부를 간단히 체크하고,
본인의 진행률을 확인할 수 있는 모바일 우선 웹앱(PWA)을 만든다.
관리자는 전체·개인·샘별 진행상황과 달성률 분포 및 순위를 확인할 수 있다.

앱 제목은 **기도운동 1달 도전**으로 한다.

## 2. 핵심 요구사항

### 2.1 기간
- 도전 기간은 30일 고정이 아니라 **1개월**이다.
- 관리자가 시작일을 지정한다.
- 기본 종료일은 **시작일을 포함하여 다음 달 같은 날짜의 전날까지**로 계산한다.
  - 예: 2026-09-22 시작 → 2026-10-21 종료.
- 월말처럼 다음 달에 같은 날짜가 없는 경우에는 시스템이 달력 규칙에 따라 종료일을 계산하되,
  관리자 페이지에서 종료일을 직접 수정할 수 있게 한다.
- 실제 체크 대상 요일은 **월요일~토요일**이며 일요일은 제외한다.

### 2.2 기도 완료 체크
- 사용자는 달력에서 날짜를 직접 눌러 체크한다.
- 체크 가능한 날짜는 **오늘과 어제**뿐이다.
  - 예: 오늘이 17일이면 16일과 17일만 체크/취소 가능.
- 한 번 누르면 완료, 다시 누르면 취소한다.
- 일요일, 미래 날짜, 시작일 이전, 종료일 이후, 이틀 이상 지난 날짜는 비활성화한다.
- 화면뿐 아니라 서버에서도 동일한 규칙을 검증해 요청 조작을 차단한다.
- 모든 날짜 판정은 **Asia/Seoul** 기준으로 처리한다.

### 2.3 달성률
- 분모: 시작일부터 오늘까지 도래한 월~토 체크 대상일 수.
- 분자: 그 기간 중 사용자가 완료한 날짜 수.
- 오늘이 시작일 이전이면 0%로 표시한다.
- 도전 종료 후에는 전체 도전 기간을 분모로 고정한다.

## 3. 로그인 및 자동 로그인

### 3.1 로그인 방식
사용자가 제안한 방식을 그대로 사용한다.

- 아이디: **이름**
- 비밀번호: **전화번호**
- 전화번호는 숫자만 정규화하여 입력받는다.
- 전화번호 원문을 비밀번호처럼 DB에 저장하지 않는다.
- 서버에서 Argon2id 또는 이에 준하는 안전한 비밀번호 해시로 저장·검증한다.

동명이인 가능성이 있으므로 내부적으로는 고유 사용자 ID를 사용하고,
이름+전화번호 조합으로 계정을 식별한다.

### 3.2 최초 로그인/등록 흐름
1. 이름 입력
2. 전화번호 입력
3. 샘 선택
4. 등록 및 로그인
5. 이후 자동 로그인

샘 선택 시 아래 두 값 모두로 검색할 수 있다.
- 샘 이름
- 샘리더 이름

샘 정보는 나중에 **내 정보**에서 수정 가능하다.

### 3.3 자동 로그인
- 첫 로그인 성공 시 서버가 임의의 긴 세션 토큰을 발급한다.
- 브라우저에는 **Secure + HttpOnly + SameSite=Lax** 쿠키로 저장한다.
- DB에는 토큰 원문이 아닌 해시만 저장한다.
- 세션은 장기 유지하며 사용 시 만료를 갱신하는 rolling session 방식으로 구현한다.
- 사용자가 직접 로그아웃하면 해당 세션을 즉시 폐기한다.
- 관리자 페이지에서 특정 사용자의 세션을 강제 종료할 수 있는 구조를 지원한다.
- 전화번호 자체를 localStorage에 저장하지 않는다.

## 4. 외부 DB 및 서버 구성

### 4.1 기술 스택
- Frontend/Server: **Next.js + TypeScript**
- External DB: **Supabase PostgreSQL**
- Hosting: **Vercel**
- Styling: 모바일 우선 반응형 CSS 또는 Tailwind CSS
- PWA: Web App Manifest + 홈 화면 아이콘

Supabase는 이번 프로젝트에서 외부 PostgreSQL 서비스로 사용하며,
사용자 인증은 요구사항에 맞춘 이름+전화번호 기반 커스텀 인증/세션으로 구현한다.

### 4.2 환경변수
서버 전용 비밀값은 GitHub에 커밋하지 않는다.

예:
- `DATABASE_URL`
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `SESSION_SECRET`

`.env*`는 `.gitignore` 처리하고 Vercel 환경변수로 배포한다.

## 8. 순위 규칙

- 시작일부터 현재까지의 달성률 기준 내림차순.
- 달성률이 같으면 공동순위.
- 일반 사용자 화면에는 전체 순위를 노출하지 않고 관리자 화면에서만 확인한다.

## 9. 모바일/PWA

- 360px 폭 휴대폰에서도 정상 사용 가능.
- 터치 대상 최소 크기를 충분히 확보한다.
- 홈 화면에 추가 가능한 PWA로 제공한다.
- 앱 아이콘은 기도/체크를 직관적으로 표현한다.
- 192x192, 512x512 아이콘과 maskable 아이콘을 제공한다.

## 10. 보안

- 전화번호 평문을 비밀번호 데이터로 저장하지 않는다.
- 로그인 실패 메시지로 회원 존재 여부를 과도하게 노출하지 않는다.
- 세션 쿠키는 HttpOnly/Secure/SameSite 속성을 사용한다.
- DB 접근은 서버를 통해 수행한다.
- 관리자 API는 role 검증을 서버에서 수행한다.
- 체크 가능한 날짜 검증도 서버에서 재검증한다.
- 개인정보와 환경변수는 GitHub 저장소에 커밋하지 않는다.

## 11. 테스트 기준

### 날짜/체크
- 오늘이 17일일 때 16일·17일만 수정 가능
- 15일 이전 날짜 수정 불가
- 일요일 수정 불가
- 미래 날짜 수정 불가
- 시작일 이전 수정 불가
- 종료일 이후 수정 불가
- 한 번 클릭: 완료
- 다시 클릭: 취소

### 달성률
- 월~토만 분모에 포함
- 오늘 이후 날짜는 분모에서 제외
- 도전 종료 후 전체 기간 기준으로 고정
- 일요일 체크 데이터가 잘못 들어와도 집계에서 제외

### 인증
- 이름+전화번호 로그인 성공/실패
- 전화번호 평문 미저장
- 로그인 후 브라우저 재실행 시 자동 로그인
- 로그아웃 후 세션 무효화
- 타 사용자 세션으로 기록 수정 불가

### 권한
- 일반 사용자의 관리자 페이지/API 접근 차단
- 관리자만 전체 통계 조회 가능

### UI
- 360px 모바일 폭 테스트
- 달력 터치 가능 영역 테스트
- 샘 이름/샘리더 이름 모두 검색 가능
